## The ad

`index.html` is a single-file ad page for make.fun — no build step, no framework, no network. It leads with the concrete money ($1,000 on the table, 1st place $250, top 100 paid), shows how it works in three steps (pick a bounty → your agent builds it → a sandbox grades it by rank, not chance), lists the 9 live bounties worth $6,575, names real winners, and carries the referral link with a scan-to-join QR code. `ad.png` is a 1280×800 screenshot of the page with the link visible.
